
# Análisis de Probabilidad y Estadística

## Descripción

Proyecto de análisis exploratorio de datos desarrollado en Python como práctica de conceptos fundamentales de probabilidad y estadística.

A partir de un conjunto de datos de respuestas a una encuesta, se estudian características demográficas, preferencias personales y hábitos de consumo mediante estadísticas descriptivas, visualizaciones y cálculos de probabilidad.

## Objetivos

- Calcular medidas de estadística descriptiva, como la media, mediana, moda y desviación estándar.
- Identificar valores faltantes y posibles valores atípicos (*outliers*).
- Analizar y comparar las distribuciones de edad y peso según el género.
- Calcular probabilidades marginales y conjuntas para variables relacionadas con el consumo de tabaco y alcohol.
- Explorar las relaciones entre variables y representarlas gráficamente.
- Interpretar los resultados y discutir las limitaciones de las conclusiones obtenidas.

## Dataset

Se utiliza el archivo `people_responses.csv`, que contiene respuestas a una encuesta con aproximadamente 150 columnas.

Entre las variables disponibles se encuentran:

- **Características demográficas:** edad, altura, peso y género.
- **Educación y familia:** nivel educativo, cantidad de hermanos y condición de hijo único.
- **Preferencias musicales:** géneros como rock, pop, música clásica y dance.
- **Hábitos de consumo:** variables relacionadas con el consumo de tabaco y alcohol.

Los datos se cargan directamente desde un repositorio público de GitHub.

## Tecnologías utilizadas

- **Python:** lenguaje de programación.
- **Pandas:** manipulación y análisis de datos.
- **NumPy:** operaciones numéricas.
- **Matplotlib:** creación de gráficos.
- **Seaborn:** visualización estadística.
- **Google Colab:** desarrollo y ejecución del notebook.

## Metodología

1. Carga e inspección inicial del conjunto de datos.
2. Cálculo de medidas estadísticas descriptivas.
3. Detección y análisis de valores faltantes y atípicos.
4. Comparación de distribuciones según el género.
5. Cálculo y representación de probabilidades marginales y conjuntas.
6. Análisis de asociaciones entre variables seleccionadas.
7. Interpretación de los resultados y discusión de posibles escenarios.

## Cómo ejecutar el proyecto

1. Abrir el notebook en Google Colab.
2. Ejecutar las celdas en orden.
3. Verificar que el entorno tenga instaladas las bibliotecas necesarias.
4. Consultar las salidas de las celdas para observar los cálculos, gráficos y conclusiones.

El dataset se carga desde una URL pública, por lo que no es necesario descargar manualmente el archivo CSV.

## Estado del proyecto

Práctica de probabilidad y estadística centrada en el análisis exploratorio de datos, la visualización y la interpretación de relaciones entre variables.
